- Pest: 204 passed / 1,427 assertions and 1 PostgreSQL-only integration test skipped by its environment guard on the host. Recent coverage includes password reset session revocation; queued webhook payload redaction during anonymization; inbox assignment-prop authorization; stalled free-form message recovery; encrypted session configuration, archived-customer follow-up cancellation through restore, stated-return-date reminder cancellation and send suppression; pending/uncertain free-form reply duplicate prevention; automation-view-only access without template disclosure; expired unresolved webhook payload redaction while preserving recent retryable callbacks and redacting stale unprocessed inbound events; configurable stale callback health status; provider-template removal/rejection/reappearance synchronization and linked automation shutdown; timestamp-ordered orphan delivery status callbacks; queue/scheduler readiness; customer request authorization; security headers and proxy trust; privileged MFA; account email uniqueness; customer privacy workflows; webhook payload retention and opt-out handling. Prior verification covers inbox-template reply idempotency and uncertain-delivery recovery, PostgreSQL concurrency, and encrypted backup/restore. Playwright: 19 Chromium tests passed, including the staff invitation UI rejection without secure mail transport and owner-role delegation guard, authenticated mobile automation create/enable/edit, mobile business contact persistence, the MFA-protected owner health page showing a stale callback, account session revocation, authorized customer CSV import/export, mobile customer anonymization, settings-save confirmation, role-control visibility, audit-export filter alignment, inbox triage, review editing, service/category workflows and a narrow-page read-only sweep. Deployment/rollback shell control flow passes its fake-Docker test, including automatic previous-release recovery when web or worker health checks fail.
- PHPStan/Larastan, Pint, TypeScript, ESLint, Prettier and Vite production build passed. Inertia pages are lazy-loaded; the latest app entry is 45.54 kB and the largest built chunk is 356.81 kB.
- Composer validation and locked dependency audit passed; Docker Compose configuration parsed successfully.
- The application has 85 registered non-vendor routes and no active booking, appointment, availability, payment or subscription endpoints.
