## Local verification

- Pest: 141 passed / 975 assertions and 1 PostgreSQL-only integration test skipped by its environment guard on the host. New review tests cover permission-checked edits, business-scoped exports, CSV formula mitigation, audit records, and minimal audit metadata. Audit export tests verify safe columns, scope, permissions and formula mitigation. Prior verification covers single-business middleware, messaging settings, staff deletion, template deletion, scheduled-message controls, service categories, queue health, PostgreSQL concurrency and encrypted backup/restore. Playwright: 10 Chromium tests passed, including mobile review editing as well as owner MFA/settings, staff removal, template deletion, service/category workflows, customer/visit flows, inbox controls and permission-gated page coverage. Deployment/rollback shell control flow passes its fake-Docker test.
- PHPStan/Larastan, Pint, TypeScript, ESLint, Prettier and Vite production build passed. Inertia pages are lazy-loaded; the latest app entry is 45.14 kB and the largest built chunk is 356.81 kB.
- Composer validation and locked dependency audit passed; Docker Compose configuration parsed successfully.
- The application has 84 registered non-vendor routes and no active booking, appointment, availability, payment or subscription endpoints.

## Not verified here

The host runtime lacks `pdo_pgsql`; `php artisan migrate:status` fails with “could not find driver.” Disposable PostgreSQL tests cover fresh migrations, concurrent message claiming, stale-message recovery and an encrypted backup/restore into a new database. The configured database migration state, existing business data and existing-dataset constraints were not inspected. The original folder-grouped commits and subsequent catalog commits have been pushed to `main` with no co-author trailers. Broader authenticated CRM write workflows and full accessibility review are still needed. Live Meta/WhatsApp and email behavior, external privacy/legal compliance, production deployment, remote backup copy/retention and production restoration remain unverified.
