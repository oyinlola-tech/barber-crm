## Local verification

- Pest: 162 passed / 1,141 assertions and 1 PostgreSQL-only integration test skipped by its environment guard on the host. Coverage includes per-response CSP nonce matching and rotation, production-secure session defaults, privileged MFA, case-insensitive account email uniqueness, webhook payload retention, database-outage health reporting, and customer opt-out persistence. Prior verification covers inbox-template reply idempotency and uncertain-delivery recovery, permission checks, PostgreSQL concurrency, and encrypted backup/restore. Playwright: 11 Chromium tests passed on a fresh production bundle, including keyboard skip-link navigation and customer profile updates without note permission. Deployment/rollback shell control flow passes its fake-Docker test, including automatic previous-release recovery when web or worker health checks fail.
- PHPStan/Larastan, Pint, TypeScript, ESLint, Prettier and Vite production build passed. Inertia pages are lazy-loaded; the latest app entry is 45.54 kB and the largest built chunk is 356.81 kB.
- Composer validation and locked dependency audit passed; Docker Compose configuration parsed successfully.
- The application has 85 registered non-vendor routes and no active booking, appointment, availability, payment or subscription endpoints.

## Not verified here

The host runtime lacks `pdo_pgsql`; `php artisan migrate:status` fails with “could not find driver.” Disposable PostgreSQL tests cover fresh migrations, concurrent message claiming, stale-message recovery and an encrypted backup/restore into a new database. The configured database migration state, existing business data and existing-dataset constraints were not inspected. The original folder-grouped commits and subsequent catalog commits have been pushed to `main` with no co-author trailers. Broader authenticated CRM write workflows and full accessibility review are still needed. Live Meta/WhatsApp and email behavior, external privacy/legal compliance, production deployment, remote backup copy/retention and production restoration remain unverified.
